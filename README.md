# Proyecto de Informática – Comercio Exterior

## Análisis de las exportaciones argentinas de yerba mate 2020–2024

### 1. Tema del proyecto

El proyecto corresponde a la carrera de Comercio Internacional y Despachante de Aduanas.

El tema seleccionado es el análisis de las exportaciones argentinas de yerba mate durante el período 2020–2024.

El objetivo es analizar la evolución de las exportaciones durante cinco años, utilizando información estadística y documentación relacionada con el comercio exterior.

---

## 2. Objetivo

El objetivo del proyecto es transformar información proveniente de archivos de Excel y Word en un análisis organizado y presentarlo mediante un sitio web.

Se busca observar la evolución de las exportaciones argentinas de yerba mate entre 2020 y 2024, identificar cambios y tendencias y organizar la información de manera clara para su consulta.

---

## 3. Información utilizada

Para realizar el proyecto se trabajó con:

- 2 archivos de Excel con información relacionada con el análisis estadístico.
- 1 archivo de Word con información complementaria relacionada con Comercio Exterior.
- Información obtenida y analizada mediante las herramientas indicadas en la consigna.

Los archivos originales fueron conservados en el Drive personal del estudiante.

---

## 4. Herramientas utilizadas

De acuerdo con las herramientas establecidas en la consigna, se utilizaron:

- Perplexity
- Cuaderno Gemini
- Gemini para el análisis
- Claude para la generación del HTML
- Netlify para la publicación del sitio web
- GitHub para documentar el proceso y presentar el proyecto

---

## 5. Etapas del trabajo

### Etapa 1 – Selección del tema

Se seleccionó un tema relacionado con la carrera de Comercio Internacional y Despachante de Aduanas.

El tema elegido fue la evolución de las exportaciones argentinas de yerba mate durante el período 2020–2024.

### Etapa 2 – Recolección y organización de la información

Se utilizaron dos archivos de Excel y un archivo de Word como material de trabajo.

Los datos fueron organizados para poder realizar posteriormente el análisis y la presentación de los resultados.

### Etapa 3 – Investigación

Se utilizó Perplexity como herramienta de búsqueda e investigación para complementar y contextualizar la información necesaria para el proyecto.

### Etapa 4 – Análisis

Los archivos y la información recopilada fueron trabajados mediante Cuaderno Gemini y Gemini como herramienta destinada al análisis.

A partir de la información disponible se identificaron datos y tendencias relacionados con las exportaciones de yerba mate durante el período seleccionado.

### Etapa 5 – Generación del sitio web

Una vez realizado el análisis, se utilizó Claude para generar el código HTML del sitio web.

El resultado fue una página web que organiza la información del proyecto y presenta el análisis de las exportaciones argentinas de yerba mate 2020–2024.

### Etapa 6 – Publicación

El archivo HTML terminado fue publicado utilizando Netlify.

Sitio web:

https://proyecto-yerbamate.netlify.app/

### Etapa 7 – Documentación en GitHub

Finalmente, se creó este repositorio de GitHub para documentar las etapas realizadas durante el proyecto y facilitar su evaluación.
